# tiny-chess-01

A chess engine written in a single 4 KB Python file. Standard library only, no network calls, deterministic play. Built for the tiny-chess-01 size-coding challenge: it reads the trial brief from its environment and plays its games one after another.

## Run it

```sh
python main.py
```

The engine only needs Python 3.13's standard library. The harness supplies MAKEFUN_ENV_URL, MAKEFUN_PROMPT_FILE and MAKEFUN_TRIAL_SEED; none are required to import or run the file locally.
